# BeeStyle - E-Commerce Platform & Dashboard

BeeStyle E-Commerce Template & Management System (Phoenix Theme v1.24.0).

## 🚀 Getting Started

### 1. Run local server
To start the local preview server, run:
`powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
`
Then access http://localhost:8080 in your browser.

### 2. Database
Import database.sql into MySQL / MariaDB for the e-commerce database schema and initial setup.
